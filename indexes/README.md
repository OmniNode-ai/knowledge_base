# Indexes

Auto-generated indexes for browsing artifacts by date, topic, or type. Do not edit directly — run `uv run python scripts/generate_indexes.py` to regenerate from current artifact frontmatter.

- [By date](chronological.md)
- [By topic](by-topic.md)
- [By type](by-type.md)
- [Public proof index](../reference/public-proof-index.md) — releases, reproducible checks, and evidence limits

The index files in this directory are rebuilt from frontmatter on every change. If you add or modify an artifact, regenerate the indexes before committing.
