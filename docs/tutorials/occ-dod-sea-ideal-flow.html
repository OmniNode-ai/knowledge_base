We follow one real task: a delegation job was reporting zero cost, so the savings number the platform showed meant nothing. Tickets like this live in Linear; the code lives in GitHub. This walk follows that one ticket from "here's what done means" to "merged and proven." Three words recur: a contract writes down what done means, proof is output you can run and look at, and a gate is an automated check that won't let the work merge until that proof is really there.
