# ADR-0021: Withdrawn beta planning record

The earlier hosted-first beta planning record was never accepted and is withdrawn from public documentation. It is superseded by [ADR-0053](ADR-0053-beta-scope-local-install-own-keys.md): the beta is a local install with customer-owned model endpoints or provider keys; the hosted service follows. Read [Beta status](../reference/beta-status.md) for availability.
