# ADR-0021 (withdrawn): July 2026 Beta Priority Lock

> **Withdrawn, and superseded by [ADR-0053](ADR-0053-beta-scope-local-install-own-keys.md).**

This number recorded an internal ordering of work for a beta planned in July 2026. A
work-priority ordering is not an architecture decision, so the record was never accepted
and its text has been removed from this repository. The number is kept so that
references to it still resolve.

The current beta scope is in [ADR-0053](ADR-0053-beta-scope-local-install-own-keys.md):
a local install that delegates to a model the user chooses, on their own computer or
their own provider key. The hosted service is not part of the beta.
