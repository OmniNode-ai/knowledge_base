# ADR-0007: Canonical Skills Migration Plan (historical)

This decision addressed two overlapping migration plans. One reference was selected so contributors would not implement conflicting definitions of the same skill boundary. Those implementation plans are historical and are not published execution instructions.

The durable rule is to maintain one canonical description of a capability and explicitly retire overlapping plans. Current skill boundaries are documented in [Skill lifecycle](../architecture/omniclaude-skill-lifecycle.md) and [Authoring an ONEX skill](../guides/authoring-an-onex-skill.md).
