# Beta status

*Availability as of 2026-10-18. The beta is local-first and bring-your-own-key.*

| Surface | Availability | Start here |
|---|---|---|
| Local install and terminal delegation | Public beta path; no OmniNode account required | [Delegation quickstart](../guides/delegation-quickstart.md) |
| Claude Code plugin | Uses the same local delegation command | [Plugin setup](../guides/delegation-quickstart.md) |
| Codex, Cursor and Gemini adapters | Integration references; availability and prerequisites are documented per adapter | [Agent adapters](../guides/delegation-quickstart.md#agent-adapters) |
| Receipts, metering and local dashboard | Included in the local quickstart | [Read the receipt](../guides/delegation-quickstart.md) |
| Local tier-0 runtime | Platform development path with no external broker or database server | [Local runtime](../guides/getting-started-local.md) |
| Hosted account creation and sign-in | Preview, not open to outside users; account access is waitlist-gated | [Cloud preview](../guides/connecting-to-the-cloud.md) |
| Hosted API keys and workflow API | Preview, not open to outside users; interface documentation is not an availability promise | [Cloud preview](../guides/connecting-to-the-cloud.md) |

Customers use their own model endpoint or provider credential and pay their provider directly. OmniNode does not sell or mark up inference. The platform is open source; only the hosted cloud deployment architecture is private.

The beta is not a published cost-saving benchmark. Metering compares token spend against a configured baseline, but a cost-and-quality claim requires a fixed task set and published evaluation evidence. No such experiment is reported here.
